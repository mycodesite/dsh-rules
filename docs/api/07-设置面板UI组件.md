# 07-设置面板 UI 组件（`src/client/RuleSection.tsx`、`src/client/index.ts`）

「规则」设置面板区：组件与 `settings.section` 注册。

## 一、`RuleSection.tsx`

### 接口 `RuleSectionProps`

```ts
interface RuleSectionProps {
  controller: RuleController
}
```

### 组件 `RuleSection`

```ts
function RuleSection({ controller }: RuleSectionProps): JSX.Element
```

无外部状态库，全部原生 HTML 元素 + 内联样式（client bundle 不 import dsh UI primitives）。

#### 内部状态

| 状态 | 类型 | 说明 |
|:--|:--|:--|
| `level` | `RuleLevel` | 当前 tab（全局/项目），切换触发 `controller.load` |
| `editing` | `{ id: string \| null; content: string } \| null` | 编辑态；`id === null` 为新建 |
| `confirmDeleteId` | `string \| null` | 待删除确认的规则 id |
| `createMenuOpen` | `boolean` | 「+ 创建」下拉是否展开 |
| `busy` | `boolean` | 操作进行中（禁用按钮） |

#### 交互映射

| 用户操作 | 行为 |
|:--|:--|
| 「刷新」按钮 | `controller.reload(level)`（重载注入 + 重拉列表） |
| 「+ 创建」→ 全局 / 项目 | 切换 `level` 并进入新建编辑态 |
| 全局 / 项目 tab | `setLevel` 切换，`useEffect` 触发 `load` |
| 列表项单击 / 菜单「编辑」 | `editing = { id, content }` |
| 设置按钮 `⋮` → 「编辑」「删除」 | 进入编辑态 / 弹删除确认 |
| 编辑框「保存」 | `create`（新建）或 `save`（覆盖），成功后关闭编辑态 |
| 编辑框「取消」 | 关闭编辑态 |
| 删除确认「删除」 | `controller.remove` |

#### 私有组件 `RuleRow`

单行规则：左图标（CSS 色块）+ 标题/文件名 + 设置按钮（`⋮`）下拉菜单（编辑/删除）；单击行进入编辑（设置按钮区域内点击除外）。菜单开合状态为每行局部状态，菜单弹出后点击页面其它位置自动关闭（与「+ 创建」下拉共用通用 hook `useClickOutside`）。

## 二、`client/index.ts`

### 常量

```ts
export const name = 'rulebase'
export const inject = ['slots', 'connection']
```

### 接口 `RuleBaseClientContext`

```ts
interface RuleBaseClientContext {
  slots: {
    inject(slot: string, register: () => unknown): void
    register(spec: Record<string, unknown>, component: ComponentType<RuleSectionProps>): unknown
  }
  connection: {
    rpc: {
      call(channel: string, endpoint: string, payload?: unknown): Promise<RpcResult<unknown>>
    }
  }
}
```

最小 client 上下文（运行时由 dsh client 框架注入），仅声明 `slots` 与 `connection`。

### `apply(ctx)`

1. 绑定 channel，把 `ctx.connection.rpc.call` 收敛为 `RuleRpc`（`call('/rulebase', endpoint, payload)`）。
2. 实例化 `RuleController`。
3. 注册 `settings.section` 贡献：

```ts
ctx.slots.inject('settings.section', () => ctx.slots.register({
  name: 'settings.section',
  id: 'rulebase',
  order: 30,
  label: () => '规则',
  inject: () => ({ controller }),
}, RuleSection))
```

- `settings.section` 的 owner props 仅 `{ close }`；数据/状态全来自 `controller`（经 `inject` 注入）。

## 设计要点

- client bundle 不 import `@deepseek-ai/dsh-client-*` 运行时包，仅 `react` + `react/jsx-runtime`（由 dsh 客户端 shell 提供）。
- 配色跟随 dsh 亮/深外观：样式使用 dsh 主题别名 token（`var(--dsw-alias-*)`，如 label-primary、bg-layer-*、border-l1、brand-primary、state-error/warn-primary、button-* 等），这些变量由 dsh 客户端在 `document.body` 上以内联 CSS 变量投影、随外观自动切换，故无需感知具体主题 class/属性。
- 下拉/菜单展开后点击页面其它位置自动关闭：由通用 hook `useClickOutside(active, onClose)` 实现（行设置菜单与「+ 创建」下拉共用）。
- UI 商品原语用原生 HTML 自绘，等价满足「刷新 / +创建下拉 / tab / 列表(图标+内容+设置下拉) / 单击编辑 / 保存取消」，无需改动设置外壳。
