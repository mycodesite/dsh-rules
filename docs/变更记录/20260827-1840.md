# 变更记录：规则设置页面交互与深色主题优化-001

## 2026-08-27

### 变更概要
「规则」设置面板（`src/client/RuleSection.tsx`）三项 UI/UX 优化：

1. **表项单击进入编辑**：由 `onDoubleClick` 改为 `onClick`，并通过 `[data-rule-actions]` 守卫排除设置按钮（`⋮`）/菜单区域内点击，避免误触编辑。
2. **菜单点击外部自动关闭**：新增通用 hook `useClickOutside(active, onClose)`，应用于行设置菜单与「+ 创建」下拉；菜单/下拉展开后点击页面其它位置自动关闭。
3. **配色跟随 dsh 亮/深外观**：`styles` 中硬编码颜色全部替换为 dsh 主题别名 token（`var(--dsw-alias-*)`），随 dsh 外观自动切换；修复深色下刷新按钮白底白字。
