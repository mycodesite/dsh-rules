设置面板项目规则跟随根因

rulebase 插件 UI 管理支未接上 session.header.cwd —— 根因在 activeAgents 近似 + 前端不订阅切换事件。
当前缺陷链路 · 设置面板获取项目 cwd 的路径
根因环节正常环节host 无"当前选中 session"态可读
根因 Rootcause · 逐行源码核实
1
设置面板项目 cwd 唯一来源是 injector.currentProjectCwd()（src/host/injector.ts:80-87），返回 activeAgents 中"最近创建的活跃 agent"的 cwd，非当前选中 session 的 cwd。
2
activeAgents 由 agent/created 填充，agent 在 ensureSession（发消息启动 turn 时，commands.ts:104→agent.ts:232）才创建；切换对话 openSession 不保证立即建 agent。
3
前端 RuleSection.tsx:47-55 useEffect 依赖 [controller, level]，切换对话时 controller 单例不变、level 是 tab 也不变 → 不重拉。
4
client/index.ts 不订阅任何切换事件——"发消息"修 host（agent/created 更新 activeAgents），"进面板"修前端（重挂载触发重拉），缺一不可，正是用户观察的现象。
5
关键约束：DSH 事件清单（docs/event-producer-consumer.zh.md）无 session/opened/activated/focused 事件——"当前选中"是前端态，host 无对应事件/服务，是 rulebase 只能用 activeAgents 近似"当前项目"的根本约束。
跟随方案对比 · 推荐 C + A 组合
方案改动层治本难度说明
C（推荐）前端→host RPC治本中controller 把当前 session.cwd 随 RPC 传 host；service.invoke 优先用前端传入 cwd（resolveCwd 已支持 p.cwd）；store.list(level,cwd) 已就绪。绕开 agent 时序，与 session.header.cwd 对齐。
A（配合）前端跟随低RuleSection useEffect 依赖加"当前 session 标识"或订阅切换事件触发重拉；client/index.ts 扩展 inject 获取 dsh client 当前 session/workspace 态。
B（备选）host治本但需 dsh 配合高injector.currentProjectCwd 改读"当前选中 session.header.cwd"——dsh host 是否暴露"当前选中 session"服务未见（事件清单无切换事件），可能需 dsh 侧新增。
